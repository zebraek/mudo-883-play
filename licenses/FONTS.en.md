# Font License List

Five typefaces ship with "88.3MHz Muwol Island". All five are licensed under the **SIL Open Font License 1.1 (OFL)**. The OFL allows the original and modified versions to be bundled, embedded and sold as part of commercial software, including games and mobile apps (OFL FAQ 1.3 and 1.4). Its conditions are: (1) the fonts may not be sold on their own, (2) the copyright notice and the full license text must be included, and (3) **a modified version may not use a Reserved Font Name (RFN)**. The table below shows how each condition is met. The `OFL.txt` / `LICENSE.txt` file in each font folder is the full license text, copied unchanged from the original distributor. Checked: 2026-09-23. Subsetting applied and re-checked: 2026-09-27.

**2026-09-27 font size reduction (M9):** every shipped font file is a subset (the originals are kept in `fonts-src/` and are not part of the build). Under the OFL a subset is a "Modified Version", so fonts that declare an RFN **were renamed**: D2Coding became **'Mudo Mono'** and Nanum Pen Script became **'Mudo Label'**. Noto Serif KR declares no RFN and keeps its name. Pretendard keeps its name because its official chunks are shipped unmodified and only some files are left out (leaving files out is not a modification). Tools: fontTools 4.64 `pyftsubset` (MIT) with brotli. Reproduce with `npm run fonts:subset`; verify with `npm run fonts:check` (part of `npm run check`).

## Subset range (common to all five, `scripts/fonts/lib.mjs`)

- **Every character actually used in the game text**: `story/**/*.ink` (without comments), `data/**/*.{json,csv,txt}`, string literals in `src/**/*.{ts,css}` (without comments, identifiers or `tests/`), and `index.html`.
- **Baseline glyphs** (always included, whatever the text): printable ASCII (U+0020-007E), **the 2,350 precomposed Hangul syllables of KS X 1001** (`scripts/fonts/ksx1001-hangul.txt`), the compatibility jamo (U+3131-3163, shown while typing commands), and UI symbols (quotation marks, dashes, ellipsis, middle dot, arrows, math signs, shapes, circled numbers, CJK brackets, Latin-1 supplement symbols and box drawing - `BASE_SYMBOLS`).
- Each font receives "the characters it originally has, intersected with the set above". Characters the original never had (for example some brackets and shapes missing from Noto) fall back to a system font, as before; `fonts:check` reports them as information. **No character that the original has may be missing from the subset**: `fonts:check` blocks that as an error (it runs in `npm run check` and `npm test`).
- Pretendard is not subset. Only the official chunks whose unicode-range is reached by the used characters drawn in the UI font are shipped (for the script, only choices, tags and cliffhanger lines; narration and dialogue use the body serif - decision of 2026-10-12, V6-03). If new text reaches another chunk, `fonts:check` catches it and `npm run fonts:subset --pretendard-only` (no Python needed) syncs the files.
- pyftsubset options: `--flavor=woff2 --unicodes-file=... --name-IDs='*' --name-legacy --name-languages='*' --notdef-outline` (default layout features such as liga, calt and kern; hinting kept, except `--no-hinting` for Nanum Pen). Renaming is done by `scripts/fonts/rename-font.py` (fontTools, `recalcTimestamp=False` for reproducibility). The same original and the same text give byte-identical output (sha1 matched over two runs).

## Glyph coverage (output of `npm run fonts:check`)

- Characters that an original font does not have are UI decorations and symbols; they fall back to a system font, as they did before subsetting (not a license issue). `fonts:check` lists them for each font. The body text's corner brackets and angle brackets are drawn from the shipped, unmodified Pretendard chunks, and `░▒▓≡` from the shipped Mudo Mono file, through CSS aliases (`Mudo Brackets`, `Mudo Marks`); no new files are added (2026-10-13).
- The family name in the name table of the shipped Noto files reads 'Noto Serif KR ExtraLight' (the default instance name of the Google Fonts variable font, the same for every weight). It does not affect rendering or licensing; CSS selects it as `font-family: 'Noto Serif KR'`.
- Name tables of the renamed fonts (`fonts:check` checks them every run): IDs 1/4/16 'Mudo Mono', ID 6 'MudoMono-Regular'; IDs 1/4 'Mudo Label', ID 6 'MudoLabel-Regular'. No name record still contains 'D2Coding', 'Nanum' or 'Naver', in Latin or in Hangul (the ID 0 copyright notice and the ID 10 origin description are forms the OFL FAQ allows).

## How the notice obligations are met

- The full original license text is included, unmodified, in each font folder (table above). The release build (`dist/`) copies `public/` as is, so the texts are also inside the web and app packages. This document (`public/licenses/FONTS.md`, with this English version `FONTS.en.md`) ships with them.
- The two modified fonts (Mudo Mono and Mudo Label) also keep the original copyright notice, the OFL text and an origin description inside their name tables (OFL sections 1 and 3).
- The credits screen and `docs/asset_credits.md` list each font's name, copyright holder and the OFL. Modified fonts are credited as "a modified version (subset, renamed) of ...". The OFL does not "require" credits, but including the copyright notice and the license is a mandatory condition, and crediting is customary.
